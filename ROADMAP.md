# Дорожная карта

Версии — [SemVer](https://semver.org/lang/ru/). Статусы: **сделано**, **в работе**, **запланировано**.
Журнал изменений — в [CHANGELOG.md](CHANGELOG.md). Номер версии в коде один: `fast_parser.__version__`.

Веб-интерфейс стоит раньше моделей: ленту уже можно читать, а категория, тональность и оценка недостоверности подставятся в те же фильтры, когда появятся.

| Этап | Версия | Статус | Что входит |
| --- | --- | --- | --- |
| Сбор RSS и региональный каталог | 0.1.0 | сделано | Федеральные и региональные источники (все 89 субъектов), догон при запуске, дедупликация, SQLite, заглушки пайплайна |
| Веб-интерфейс | 0.2.0 | сделано | Локальный интерфейс одной командой: лента с фильтрами, карточка, источники, покрытие регионов, сводка, запуск сбора. JSON API |
| Категории и тональность | 0.3.1 | сделано | 12 рубрик и шкала positive / neutral / negative. Слова и RSS сразу, rubert-tiny2 при extra ml, калибровка новостного тона. Оценка на ручной выборке: `fast-parser eval` |
| Хранение и поиск | 0.4.0 | сделано | PostgreSQL 16 с разделами по месяцу, русский полнотекст, фильтры API и CLI, архив Parquet, DuckDB для сводки, перенос из SQLite. Векторный слот пустой |
| Качество рубрик | 0.4.1 | сделано | Линейная голова на замороженном rubert-tiny2. Метрика — 3 фолда, не подгонка под всю выборку. Неуверенные случаи можно отдать локальной LLM, по умолчанию выключено |
| Telegram | 0.5.0 | запланировано | Сбор каналов через Telethon. Юзернеймы уже лежат в каталоге |
| Оценка недостоверности | 0.6.0 | запланировано | `fake_score`: надёжность источника, кластеризация одного события у разных источников, сверка с сайтами фактчекинга |
| Экспорт в RAG-5060 | 0.7.0 | запланировано | Отдельный контур PostgreSQL + Qdrant + эмбеддинги BGE-M3, свой tenant и collection. Слот embedding в статьях уже есть |
| VK и X | 0.8.0 | запланировано | Источники помимо RSS и Telegram. Состав площадок уточняется ближе к этапу |
