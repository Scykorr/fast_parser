# Дорожная карта

Версии — [SemVer](https://semver.org/lang/ru/). Статусы: **сделано**, **в работе**, **запланировано**.
Журнал изменений — в [CHANGELOG.md](CHANGELOG.md). Номер версии в коде один: `fast_parser.__version__`.

Веб-интерфейс стоит раньше моделей: ленту уже можно читать, а категория, тональность и оценка недостоверности подставятся в те же фильтры, когда появятся.

| Этап | Версия | Статус | Что входит |
| --- | --- | --- | --- |
| Сбор RSS и региональный каталог | 0.1.0 | сделано | Федеральные и региональные источники (все 89 субъектов), догон при запуске, дедупликация, SQLite, заглушки пайплайна |
| Веб-интерфейс | 0.2.0 | сделано | Локальный интерфейс одной командой: лента с фильтрами, карточка, источники, покрытие регионов, сводка, запуск сбора. JSON API |
| Категории и тональность | 0.3.0 | сделано | 12 рубрик и шкала positive / neutral / negative. Слова и рубрики RSS сразу, rubert-tiny2 при extra ml, запасной LLM выключен |
| Telegram | 0.4.0 | запланировано | Сбор каналов через Telethon. Юзернеймы уже лежат в каталоге |
| Оценка недостоверности | 0.5.0 | запланировано | `fake_score`: надёжность источника, кластеризация одного события у разных источников, сверка с сайтами фактчекинга |

| VK и X | 0.7.0 | запланировано | Источники помимо RSS и Telegram. Состав площадок уточняется ближе к этапу |
